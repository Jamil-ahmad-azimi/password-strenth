# 🔐 Password Strength Checker

A sleek and interactive web app that helps users check the strength of their password in real time. Built with **HTML**, **CSS**, and **JavaScript**, this tool provides visual feedback and strength messages based on password length.

## ✨ Features

- ✅ Real-time password strength evaluation
- 🔁 Toggle visibility (Show/Hide password)
- 🎨 Stylish and responsive design
- 🧠 Beginner-friendly JavaScript logic

## 🧪 Password Strength Logic

- **Weak**: Less than 4 characters
- **Medium**: 4 to 7 characters
- **Strong**: 8 or more characters
